# claude-task

A CLI tool that integrates GitHub Projects with Claude Code to automatically process Issues with Claude.

## Requirements

- macOS (uses Apple Seatbelt for sandboxing)
- [gh](https://cli.github.com/) - GitHub CLI
- [ghq](https://github.com/x-motemen/ghq) - Repository management
- [git-wo](https://github.com/kfly8/git-wo) - Worktree management
- [jq](https://jqlang.github.io/jq/) - JSON processing
- [Claude Code](https://claude.ai/claude-code) - Claude CLI

## Setup

### 1. Install Dependencies

```bash
brew install gh ghq jq

# Install git-wo
# See https://github.com/kfly8/git-wo

# Install Claude Code
curl -fsSL https://claude.ai/install.sh | bash
```

### 2. Install claude-task

```bash
git clone https://github.com/kfly8/claude-task.git
cd claude-task

# Add to PATH (add to .bashrc or .zshrc)
export PATH="$PWD/bin:$PATH"
```

### 3. Prepare GitHub Project

Create a Status field with the following options:

| Status | Description |
|--------|-------------|
| Ready | Waiting for task |
| WIP | Work in progress |
| Review | Awaiting review |
| Blocked | Blocked |
| Done | Completed |

### 4. Initialize Project

```bash
claude-task init https://github.com/users/YOUR_NAME/projects/NUMBER
```

This generates `config.sh` containing the Project ID and status field information.

## Usage

### Assign an Issue to Claude

```bash
claude-task assign https://github.com/OWNER/REPO/issues/42
```

**Options**:
| Option | Description |
|--------|-------------|
| `--dry-run` | Preview only, no execution |
| `--no-skip` | Don't use `--dangerously-skip-permissions` |
| `--no-sandbox` | Disable sandbox (not recommended) |

### Update Status (executed by Claude)

On task completion:
```bash
claude-task request-review <PR_URL>
```

When blocked:
```bash
claude-task report-blocked "<reason>"
```

## Workflow

```
┌─────────────────────────────────────────────────────────────┐
│ claude-task assign <ISSUE_URL>                              │
└─────────────────────────────────────────────────────────────┘
                           │
                           ▼
              ┌────────────────────────┐
              │ 1. Fetch issue content │
              │ 2. Status → WIP        │
              │ 3. Create worktree     │
              │ 4. Create context.json │
              └────────────────────────┘
                           │
                           ▼
              ┌────────────────────────┐
              │   Start Claude Code    │
              │     (in sandbox)       │
              └────────────────────────┘
                           │
              ┌────────────┴────────────┐
              ▼                         ▼
    ┌─────────────────┐       ┌─────────────────┐
    │ Success         │       │ Blocked         │
    │ request-review  │       │ report-blocked  │
    │ Status → Review │       │ Status → Blocked│
    └─────────────────┘       └─────────────────┘
```

## File Structure

```
claude-task/
├── bin/
│   └── claude-task           # Main entry point
├── libexec/
│   ├── claude-task-init      # Project initialization
│   ├── claude-task-assign    # Issue assignment
│   ├── claude-task-request-review   # Status update (on success)
│   └── claude-task-report-blocked   # Status update (when blocked)
├── sandbox/
│   └── claude-task.sb        # Sandbox profile
├── config.sh                 # Config file (generated by init)
└── README.md
```

## Security

To make `--dangerously-skip-permissions` somewhat safer, file access is restricted using Apple Seatbelt (sandbox-exec). Use at your own risk.

### Restrictions

| Target | Permission |
|--------|------------|
| worktree directory | Read/Write |
| Main repository .git | Read/Write (for worktree operations) |
| ~/.claude, ~/.claude.json | Read/Write |
| /tmp, /var | Read/Write |
| Home directory (except above) | Read only |
| Network | Unrestricted |

### Sandbox Profile

Customize via `sandbox/claude-task.sb`.
